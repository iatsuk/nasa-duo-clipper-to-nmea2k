# Верификация и оставшиеся ограничения

## Что проверено программно

На 8 сентября 2026:

- Декодер собирается системным GCC 13 с `-Wall -Wextra -Werror`.
- Тестируется именно `lib/duet_core/src/duet.cpp`, используемый прошивкой.
- Пройдены синтетические кадры: 12,3 м / 5,4 узла; футы/mph; км/ч; ноль;
  OUT; TRIP; потерянные единицы; меню; неполный кадр; неверный адрес.
- Проверены устаревание через 2000 мс, переход таймера через ноль,
  немедленное сбрасывание испорченного значения и отсутствие продления
  срока годности при служебных LCD-командах.
- 20 000 шумовых входов проверены с AddressSanitizer и UndefinedBehaviorSanitizer.
  В контейнере LeakSanitizer не работает из-за ограничения `/proc`, поэтому
  локальный запуск использовал `ASAN_OPTIONS=detect_leaks=0`; ASan/UBSan включены.
- Скрипт энергобюджета запущен и его центральный пример сверен с документацией.

```sh
python3 tools/test_host.py
python3 tools/power_budget.py
```

Полная локальная сборка ESP32 была заблокирована при сетевой загрузке
платформы PlatformIO. Затем **обе конфигурации ESP32 успешно собраны в GitHub
Actions**, включая тесты с ASan/UBSan и публикацию диагностической прошивки:
[успешный запуск](https://github.com/iatsuk/nasa-duo-clipper-to-nmea2k/actions/runs/34212355602),
commit `ad6deb186b20723d602d2585146b105f4b6d39a3`.
Проверены обычная конфигурация и конфигурация с включённой передачей/offset −1,2 м.
Для последующих изменений смотреть результат CI на их commit.

## Что не проверено

Ни одного реального электрического измерения/захвата вашего NASA, работы на
ESP32, совместимости с MFD, сохранения точности при помехах, корпуса или печати.
Нет Gerber/DRC/ERC для автономного эхолота. Компиляция и тесты не заменяют их.
`tests/fixtures.h` содержит синтетические кадры по опубликованной карте,
**не реальные записи с устройства**.

## Существенные программные ограничения

- Поддерживается ровно карта семи цифр опубликованного Duet и полный кадр
  записи 137 бит с адреса 0. Другие ревизии/частичные записи отвергаются.
- SPI mode 3 и фактическая длина кадра должны быть подтверждены анализатором.
  Приёмник не может замедлить NASA: необходимо проверить отсутствие потерь
  на реальной скорости. Статические очереди снижают риск, но не доказывают его отсутствие.
- У LCD-протокола нет CRC. Ошибка, превращающая одну допустимую цифру в другую,
  может остаться незамеченной. Прошивка не повышает точность/надёжность эхолота NASA.
- Обнаружение временного пропадания эха зависит от признаков на экране NASA.
  Сохранившееся правдоподобное, но неверное число обнаружить автоматически нельзя.
- Нулевой offset NASA подтверждается человеком; прошивка не читает EEPROM NASA.
- STW=0 не различает неподвижность, обрыв датчика и застрявшую крыльчатку.
- TRIP/TOTAL скрывают скорость; для скрытого прибора требуется экран SPEED.
- NMEA Product Information сообщает отсутствие сертификации. Код производителя
  2046 взят как default библиотеки; это не присвоенный коммерческий код NASA.
- Address claim/ISO requests обслуживает библиотека. Сохранение смены адреса и
  конфигурации instances во flash здесь не реализовано; после старта снова адрес 32
  с последующим разрешением конфликта. Постоянную привязку MFD проверить.
- Bus-off recovery, EMC, защита от импульсов и соответствие полному стандарту
  NMEA 2000 не подтверждены. LEN=0 верен только при отключённом NET-S.

## Журнал испытаний владельца

| Проверка | Ожидается | Фактический результат |
|---|---|---|
| Модель, PCB, PIC, HT1621 | Совпадение с картой | Не измерено |
| Питание 5 В / 3,3 В | Допуск, нет перегрева | Не измерено |
| Буфер на входных 5 В | Выход ≤3,3 В номинально | Не измерено |
| LCD захват | 137 бит, адрес 0, правильный порядок | Не измерено |
| Все единицы и несколько чисел | Совпадение с NASA | Не измерено |
| OUT, tap disconnect, меню | NA; timeout ≤2 с + период CAN | Не измерено |
| Смещение глубины | Только одна поправка | Не измерено |
| Сопротивление CAN до/после | Около 60 Ом, без изменения | Не измерено |
| MFD и источник STW/depth | Верные значения и реакция на NA | Не измерено |
| Перезапуск/конфликт адресов/bus-off | Предсказуемое восстановление | Не измерено |
| Мотор/помпа/зарядка | Нет новых ложных значений | Не измерено |
| Средний и пусковой ток | Записать В, мА, Вт и режим | Не измерено |
| Час в закрытом корпусе | Записать нагрев/стабильность | Не измерено |

Для автономной версии добавить записи эха, испытания динамического диапазона,
минимальной/максимальной глубины и помех. Результаты сохранять отдельными файлами
с датой, номером аппаратной ревизии и commit прошивки.
