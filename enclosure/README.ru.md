# Корпус дополнительного адаптера

`adapter.scad` — параметрический шаблон OpenSCAD для сухого помещения.
**Он не вмещает и не заменяет NASA Duet.** Параметры по умолчанию дают
внешний размер приблизительно 125×90×43 мм с крышкой. Это предварительная
компоновка нескольких модулей, не обещанная миниатюрная коробка автономного эхолота.

1. Собрать электронику, измерить габарит вместе с разъёмами и изгибами проводов.
2. Изменить `inner_x/y/z`. Учесть четыре угловые стойки: они отнимают пространство.
3. Сделать съёмную изолирующую монтажную пластину по расположению модулей.
   Зафиксировать её и платы механически; не оставлять их лежать на проводах.
   В шаблоне предусмотрены опорные рейки, но отверстия модулей не выдуманы.
4. Выбрать реальные вводы под кабели. `gland_d=0` оставляет стенки закрытыми:
   сначала приложить детали, затем просверлить отверстия. Для симметричных
   отверстий по X можно задать ненулевой диаметр.
5. Открыть в OpenSCAD, выбрать `part="base"`, F6 → Export STL. Повторить для lid.

```sh
openscad -o base.stl -D 'part="base"' enclosure/adapter.scad
openscad -o lid.stl -D 'part="lid"' enclosure/adapter.scad
```

PETG, слой 0,2 мм, 4 периметра, 30% заполнения — начальные параметры печати.
Основание печатать дном вниз, крышку наружной стороной вниз; проверить
отверстия коротким тестовым образцом. Винты под выбранный пилот 2,7 мм
подбирать по факту, не перетягивать. ASA допустим при подходящих условиях печати.

Шаблон не имеет подтверждённого IP-класса, прокладки и защиты от конденсата.
Не ставить в мокрый рундук. STL и посадка здесь не проверены физической печатью;
компоновку всей системы можно сделать только после получения размеров NASA.
