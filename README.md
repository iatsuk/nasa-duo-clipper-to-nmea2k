# NASA Clipper Duet → NMEA 2000

Проект для сохранения штатных датчиков NASA и вывода глубины и скорости относительно
воды на современный морской дисплей. Документация на русском языке.

**Статус: инженерный прототип, не готовый автономный эхолот.** Прошивка этой версии
читает цифровую линию **внутри работающего Clipper Duet**. Она не подключается прямо
к двум датчикам и не заменяет аналоговую электронику NASA. Оригинальные платы,
LCD и кнопки в первом прототипе сохраняются. Можно убрать весь прибор с панели,
оставив доступ к нему для настройки. Уменьшение корпуса и удаление LCD требуют
отдельной проверки. Совместимость именно с вашим экземпляром ещё не подтверждена.

## Почему нельзя просто подключить датчики к ESP32

В глубинном датчике находится ультразвуковой преобразователь, а генератор посылки,
приёмник слабого эха и обработка находятся в приборе. Нужен полноценный аналоговый
эхолот, а не только переходник между протоколами. Путь к полностью новой плате
описан в [плане автономного устройства](docs/standalone.ru.md).

Для первого проверяемого этапа используется опубликованная распиновка LCD
[Soenke J. Peters / ClipperDuet2N2k](https://github.com/speters/ClipperDuet2N2k).
Код приёма, контроля достоверности и отправки написан отдельно. Уровни 5 В
согласуются с 3,3 В; CAN изолирован. Прямое подключение 5 В к ESP32 не допускается.

ESP32 выбран ради встроенного CAN-контроллера и существующей библиотеки NMEA2000.
Используется классический **ESP32-WROOM-32 / ESP32-DevKitC V4**, 4 МБ flash.
Прошивка не включает радио и обновляется через USB. Это постоянно работающий прибор,
поэтому значения потребления ESP32 в deep sleep к нему не относятся.

## Что передаёт прошивка

| PGN | Значение | Период |
|---|---|---|
| 128267 | Глубина от датчика, метры; отдельный знаковый offset | 500 мс |
| 128259 | Скорость относительно воды, м/с; тип paddle wheel | 500 мс |

Исчезновение потока на 2 секунды, OUT, недопустимые цифры, меню настройки и
ошибочные единицы дают `not available`, а не старое число. TRIP/TOTAL выключают
только выдачу скорости; глубина остаётся доступной. Обновление NMEA 2 Гц не
увеличивает частоту измерения самого NASA. Общая задержка включает NASA и дисплей.
Расстояние, GPS/SOG, температура, сонограмма и управление калибровкой с MFD
в этой версии отсутствуют. Дисплей должен принимать PGN 128259 и 128267.

**Передача CAN по умолчанию выключена**: можно прошить и проверить USB-диагностику.
После испытаний она включается локальной настройкой и перемычкой ARM. Это не
подтверждение сертификации NMEA 2000 и не замена бортовым испытаниям.

## Быстрая сборка для разработчика

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install platformio==6.1.18
python tools/test_host.py
python -m platformio run
python -m platformio run -t upload
python -m platformio device monitor
```

Детали для macOS/Windows и включения передачи — в инструкции. CI собирает
диагностическую прошивку и отдельно проверяет компиляцию конфигурации передачи.
